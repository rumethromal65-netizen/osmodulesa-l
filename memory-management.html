How Memory Management Works

1. Logical vs. Physical Addresses

The CPU generates a Logical Address (e.g., 346), assuming the program's memory starts at zero. However, the program is actually stored somewhere else in the physical RAM at a real Physical Address.

2. The Relocation (Base) Register

The MMU uses a Relocation Register holding the starting physical address of the process. It adds this to the logical address to instantly find the exact location in RAM.

3. The Limit Register

To prevent a program from accessing memory outside its sandbox, the MMU checks the logical address against a Limit Register (the maximum size of the process).

4. Hardware Security Check

If Logical Address >= Limit Register, the MMU blocks it! A Segmentation Fault is thrown, and the OS aborts the process to protect other programs.
