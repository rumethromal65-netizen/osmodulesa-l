Maths Formulas

Quick Reference Guide

Limits

Standard Limit

lim (x→0) (sin x) / x = 1

Exponential Limit

lim (n→∞) (1 + 1/n)ⁿ = e

Series

Arithmetic Progression (Sum)

Sₙ = n/2 [2a + (n-1)d]

Geometric Progression (Sum to infinity)

S_∞ = a / (1 - r) , for |r| < 1

Binomial Expansion

General Theorem

(x + y)ⁿ = ⁿC₀ xⁿy⁰ + ⁿC₁ xⁿ⁻¹y¹ + ... + ⁿCₙ x⁰yⁿ

Where ⁿCₖ = n! / [k!(n-k)!]

Circles

Standard Equation

(x - h)² + (y - k)² = r²

Center at (h,k) with radius r

General Equation

x² + y² + 2gx + 2fy + c = 0

Center at (-g, -f), radius = √(g² + f² - c)

Differentiation

Power Rule

d/dx (xⁿ) = n·xⁿ⁻¹

Product Rule

d/dx (uv) = u(dv/dx) + v(du/dx)

Chain Rule

dy/dx = (dy/du) · (du/dx)

Integration

Power Rule

∫ xⁿ dx = (xⁿ⁺¹) / (n+1) + C

Integration by Parts

∫ u dv = uv - ∫ v du
